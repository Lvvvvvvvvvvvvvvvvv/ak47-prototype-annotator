AK47

把一个小书签拖进浏览器书签栏，就能在任意 HTML 页面上点选元素、写修改意见、做轻量微调，并把结构化标注复制给 AI。页面文件不会被改动。

  • 单文件
  • 支持 file://
  • 本地保存
  • 复制给 AI
  • 高对比界面
01

安装

方式 A：按住下面的黑色按钮，把它拖到浏览器书签栏。

▄︻┻┳═一…… ☆(>○<)爆头 提示：没有书签栏时，Chrome / Edge 可用 Ctrl Shift B，Mac 用 ⌘ Shift B。 请拖到书签栏使用，不是在安装页直接点击。

方式 B：新建书签，把下面代码粘贴到“网址 / URL”字段。

工具只在当前浏览器运行时注入浮层，标注保存在当前页面对应的 localStorage；微调是运行时预览，刷新后会按保存的标注重新套用。

02

使用

  1. 打开要审阅的网页、原型页或本地 HTML 文件。
  2. 点击书签栏里的 ▄︻┻┳═一…… ☆(>○<)爆头，右上角会出现标注浮窗，状态为 ON。
  3. 按住 Command Shift，再点击页面元素，即可添加一条标注或直接微调样式。
  4. 在右上角清单里可以定位、编辑、删除标注；再次点击浮窗开关可隐藏标记。
  5. 点 复制给 AI，会复制包含选择器、元素摘要、before → after 的标注清单。
