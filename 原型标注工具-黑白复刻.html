02 常驻 · 工具栏入口

浏览器插件

从浏览器插件商店安装一次，之后在工具栏点击 Dsign，就能在当前页面直接开启标注。

  • 支持 Chrome / Edge 的 Manifest V3

  • 适合高频使用和团队内长期评审
02 EXTENSION / INSTALL

安装浏览器插件

  1. 打开 Chrome Web Store 或 Microsoft Edge Add-ons，搜索 Dsign。
  2. 进入 Dsign 官方插件页，确认发布者信息后点击“添加到浏览器”。
  3. 在浏览器弹窗中确认安装，等待 Dsign 出现在扩展列表。
  4. 把 Dsign 固定到工具栏，回到要评审的网页后点击图标。
